# AI Resume Analyzer

An AI-based resume analysis web application built using Python and Flask.

## Features

- Upload resume in PDF format
- Extract text from resume
- Detect technical skills
- Calculate resume score
- Show missing skills
- Display resume statistics
- Show resume strength
- Simple and responsive web interface

## Technologies Used

- Python
- Flask
- PyPDF2
- HTML
- CSS
- Jinja2
