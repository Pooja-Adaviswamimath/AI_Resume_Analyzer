# AI Resume Analyzer

An AI-powered resume analysis web application built using Python, Flask, PyPDF2, and a locally running Llama 3.2 AI model through Ollama.

The application allows users to upload a PDF resume and receive resume analysis, skill detection, scoring, and personalized AI feedback.

## Features

- Upload resume in PDF format
- Validate uploaded files
- Extract text from PDF resumes
- Detect technical skills
- Calculate resume score
- Show detected skills
- Show missing skills
- Display resume statistics
- Show resume strength
- AI-powered resume analysis
- AI-generated strengths
- AI-generated weak areas
- AI-generated improvement suggestions
- AI-generated missing keywords
- Local AI processing using Ollama
- No paid AI API required
- Simple and responsive web interface

## AI Feature

The application uses the locally running **Llama 3.2 3B** model through **Ollama**.

The AI analyzes the extracted resume text and provides:

1. Main strengths
2. Weak areas
3. Specific improvement suggestions
4. Important missing keywords

The AI model runs locally on the user's computer, so the project does not require a paid AI API.
